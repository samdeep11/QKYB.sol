
# QKYB - Scan. Earn. Learn.

QKYB is the official **utility token** for Quick QR Scanner App. Built for real-world use, not just trading.

### 🚀 What is QKYB?
QKYB rewards users for scanning QR codes. Every scan, every learn, you earn QKYB. 
100% Public token on Polygon Network - fast, low fees, usable anywhere.

### ✨ Utility - Kahi bhi use karo
- **Scan to Earn:** Earn QKYB on every QR scan
- **Redeem in App:** Use QKYB to unlock Premium features & remove ads
- **Public Transfer:** Send to MetaMask, Trust Wallet, any exchange
- **Community Driven:** No private sale, fully public

### 📊 Tokenomics
- **Name:** QKYB

- **Network:** Polygon (MATIC)

### 🔧 How it Works
1. User scans QR in app
2. Smart contract calls `rewardUser()` 
3. User gets QKYB instantly
4. User can redeem or hold
