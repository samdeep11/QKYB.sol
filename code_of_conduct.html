🤝 QKYB - Code of Conduct

For Bareilly, UP Community - Quantum Safe Wallet

1. Our Pledge

QKYB is for everyone in UP - UP-BR region. We make a welcoming, secure, real blockchain wallet for education.

2. Real & Honest

We use real BTC-style wallets, real balance from Polygon, real explorer verification. No fake claims. Demo QKYB clearly marked as demo.

3. Security First

Never share your 12-word seed. QKYB team will NEVER ask for seed/private key. Treat like BTC — if lost, wallet gone.

4. No Scam, No Spam

Do not use QKYB for fraud, money laundering or illegal activities. Testnet POL has no real value.

5. Community

Help others in UP learn blockchain. Be respectful. Report bugs honestly.

6. Open Source

Built on open source: ethers.js, Polygon. Contribute positively.

Violation may lead to access removal.
